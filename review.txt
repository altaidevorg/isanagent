This pull request implements a background job management system with clarification tickets, auto-resume logic, and enhanced telemetry. The changes affect the agent logic, memory actor, and both terminal and web UIs. Critical issues were identified, including missing enum variants and handlers in the memory actor and the use of an undefined variable in the agent logic. Further improvements are suggested to address performance bottlenecks in the TUI rendering loop, ambiguous job selection in the auto-resume logic, and the use of blocking browser prompts in the web UI.

Using rt.block_on inside the TUI rendering loop to perform database queries is a performance bottleneck. This blocks the main UI thread, which can lead to visible stutters or unresponsiveness if the memory actor is slow or under load. It is better to fetch this data asynchronously and update the App state via a channel or shared state.
